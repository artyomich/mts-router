# Buildroot Configuration for MTS-MB-3000 Mobile Backhaul

## Overview

Buildroot configuration for MTS-MB-3000 Mobile Backhaul Router on NXP S32G3.
This configuration provides a minimal embedded Linux system optimized for MPLS-TP
forwarding, PTP grandmaster, and SyncE.
